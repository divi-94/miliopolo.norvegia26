# Prompt di avvio

Il testo seguente va incollato come obiettivo della nuova sessione:

```text
Implementa completamente l'app Norvegia 2026 in questa cartella.

Lavora autonomamente in cicli successivi fino a raggiungere la definizione di completamento oppure una condizione reale di blocco. Leggi e segui prima di tutto AGENTS.md, poi .agent/STATUS.md, .agent/PLAN.md e la specifica indicata lì. Non attendere il mio feedback fra una fase e l'altra: pianifica, implementa, verifica, autorivedi il diff, correggi e continua.

Puoi installare le dipendenze necessarie e creare commit locali di checkpoint, purché i controlli della fase siano verdi e vengano aggiunti soltanto file esplicitamente pertinenti. Non fare push, non pubblicare GitHub Pages e non effettuare altre scritture esterne.

Mantieni .agent/STATUS.md aggiornato dopo ogni ciclo. Se una stessa causa resiste a tre tentativi mirati, se serve una mia decisione materiale oppure se mancano credenziali o permessi, compila .agent/BLOCKED.md, lascia il repository in stato sicuro e fermati. Non aggirare il blocco e non dichiarare il lavoro completo.

Il risultato deve essere realmente utilizzabile da telefono, verificato visivamente, funzionante sotto il base path GitHub Pages e conforme a tutti i criteri di accettazione della specifica.
```
